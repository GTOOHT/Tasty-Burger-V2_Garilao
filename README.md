# Tasty Burger / Devil's Burger React App

A beginner-friendly React + Vite burger menu with a shopping cart, demo checkout, and product search/filter controls.

## Run in VS Code

1. Extract this ZIP.
2. Open the `MyBurgerApp` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run `npm install` to install the project dependencies.
5. Run `npm run dev` and open the local URL printed in the terminal.

## Features

- Product detail popup with quantity selection.
- Shopping cart with item count, quantity controls, remove buttons, and subtotal.
- Checkout form for customer name, phone, delivery address, and payment method.
- Order review and demo order confirmation.
- Search burger names and filter by category or price range.
- Responsive layout for desktop and mobile.

## Important

Checkout is a front-end demo only. It does not send orders to a server or process real payments. The GCash option is labeled as a demo.
